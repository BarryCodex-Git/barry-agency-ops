# SOP: Homepage Copywriting

Use this SOP when writing homepage copy for a service-business website.

## Goal

Write clear, useful, local-service homepage copy that supports conversion and SEO.

## Default Keyword Pattern

`service + location`

For new client builds, the Home Page focus keyphrase must be based on the client intake and the homepage's real ranking role.

Default pattern:

`{primary service or industry} {primary location or region}`

Brand-led pattern, when better for the Home Page:

`{company name} {primary location or region}`

Examples:

- `Plumber Garden Route`
- `H2O Plumbers Garden Route`

Use the brand-led pattern when the Home Page should rank as the main brand/local authority page and the exact service phrase makes headings sound forced.

## Voice

- Natural
- Helpful
- Confident
- Specific
- No corporate fluff
- No obvious AI phrasing
- Not a sales pitch
- Relevant, local, authentic, and human-written
- Follow `content/SOPs/local-service-seo-copywriting.md` for uniqueness, technical service realism, FAQ logic, local SEO, readability, and anti-template rules.

## Process

1. Read `content/SOPs/local-service-seo-copywriting.md`.
2. Read client intake.
3. Identify primary service and location.
4. Identify customer problem.
5. Write hero H1.
6. Write hero support copy.
7. Write CTA text.
8. Write service overview.
9. Write service card copy.
10. Write trust/why choose copy.
11. Write process copy.
12. Write local relevance copy.
13. Write unique, page-specific FAQs.
14. Prepare SEO fields.

## CTA Rule

Rotate CTA wording based on context.

Default options:

- `Get a Quote`
- `Contact Us`
- `Book a Call`

Use more specific CTAs when appropriate:

- `Request Plumbing Help`
- `Book a Drain Inspection`
- `Get Emergency Help`
- `Speak to a Local Expert`

## Section Copy Guidelines

Hero:
- Name the main service and location.
- Make the value clear fast.
- Include a practical CTA.
- Ensure the first visible intro paragraph contains the focus keyphrase or a close natural synonym for Yoast.
- H1 must read like a complete, human sentence or phrase. Avoid incomplete keyword fragments.

Services:
- Use simple service names.
- Explain outcomes, not just features.
- Home page service cards should normally use the five main Home page services from intake.
- Service card descriptions should target 35-40 words unless the layout clearly cannot support it.
- Do not use additional service-page services as Home service cards unless the user asks.

Common problems:
- Include a compact problem-intent section on Home pages where the template allows it.
- Place it after the Services cards and before Process unless the user approves a different order.
- Use 4 short cards or icon boxes that describe real customer problems tied to the primary service.
- Keep the section useful and conversion-friendly, not article-length.
- Use problem language customers search for, such as symptoms, warning signs, fault behaviour, or practical service triggers.
- Use the same standard section-heading stack as the rest of the Home Page:
  - blue bubble/eyebrow above the H2
  - matching third-party/template heading widget
  - matching separator, intro copy spacing and mobile spacing
- If creating a new section, copy or recreate the existing eyebrow and heading widget pattern instead of using basic Elementor headings.

Headings:
- H2 headings should be human-readable first, then SEO-supportive.
- Do not repeat the exact focus keyphrase across many H2 headings.
- Use close variants, brand references, location wording, and service intent naturally.
- H2 headings may be more descriptive than card headings when it helps local SEO and clarity.
- H3 headings should stay short, scannable, and service-specific.
- The blue bubble/eyebrow is part of the section heading system, not optional decoration.
- New Home Page sections must match the existing heading-area spacing between eyebrow, H2, separator and intro copy.
- Plan H2/H3 wording so Yoast does not report missing keyphrase in subheadings.
- One exact or close-match H2 is usually enough for the Home Page when the intro, SEO title, meta description, image alt text and internal structure support the focus phrase.

Why choose us:
- Use real client-specific proof where available.
- If proof is missing, keep copy modest.
- For icon/check lists using `Label: explanation`, bold the label and colon only, then keep the explanation in normal text.

Example:

`<strong>Local service area:</strong> George, Mossel Bay and nearby towns.`

Testimonials/reviews:
- The testimonials/reviews section must stay a reviews section, not a substitute service-promise or values section.
- Use real approved client testimonials or a verified Google Reviews/Trustindex-style widget when available.
- If real reviews are not available yet, use a clearly labelled placeholder state such as `Reviews coming soon` or `Google reviews pending approval`, and avoid invented quotes.
- Do not place generic service standards inside Google-style review cards because it makes the section look like fake reviews.
- Keep testimonial card H3/name text short, and keep review body copy authentic, specific, and naturally local.

FAQs:
- Answer real buying objections.
- Use the focus keyphrase, service category, location, and service-area variants naturally.
- Answers should be detailed enough to be useful, not one-line placeholders.
- Avoid keyword stuffing; write like a local human who knows the service.
- FAQ question structures must not repeat across services or pages.
- Questions should come from the actual customer concern for that service or page.

Yoast green-light checks:
- SEO title should start with the exact focus keyphrase where possible.
- Meta description should normally stay within 120-156 characters.
- Focus keyphrase or synonym should appear in the introduction.
- Keyphrase or variants should appear in useful H2/H3 headings.
- Image alt text should honestly describe the image and include service/location relevance.
- Internal links should point to Services, Service Areas, relevant service cards/pages, Blog content, or Contact where appropriate.

Hero trust bubbles:
- Keep hero trust/check bubbles very short.
- Target two words per bubble when the design uses pill-style bubbles.
- Use trust signals, not services.
- Keep both bubbles similar in character length.
- Examples: `Qualified Team`, `Insured Work`, `Local Experts`, `Clear Advice`, `Neat Work`.
- If more detail is needed, put it in the hero paragraph, not the bubble.
