## Website Build SOP

For a new client website, work inside the imported master theme/template. Do not rebuild the site from scratch, do not bypass Elementor/page-builder structure, and do not replace the provided theme with custom standalone HTML/CSS.

`New client` means converting the approved imported Elementor master/template site in place. It does not mean a blank WordPress build.

Preserve and update:
- Theme structure
- Header and footer templates
- Existing page layouts and sections
- Global styles/design system
- Forms and menus
- Existing template patterns

Replace:
- Old client copy
- Old client images, using optimized `.webp` files
- Old links, branding, service names, locations, and metadata

Never:
- Build or replace pages with WordPress block editor content
- Publish direct WordPress fallback content over Elementor pages
- Create custom standalone HTML/CSS pages
- Change `_elementor_edit_mode` or switch pages out of Elementor
- Retire, draft, blank or bypass Elementor templates as a shortcut

Ask before:
- Deactivating plugins
- Retiring templates
- Changing the page builder mode
- Rebuilding page structure
- Removing media that may still be referenced

## Confirmation Rules

Ask before changing:
- Contact details
- Form recipients
- DNS or hosting settings
- Paid software or purchases
