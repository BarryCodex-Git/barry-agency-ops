## Notes

- Home page images rotate service/location keyword variants instead of repeating the exact same focus keyword.
- Service page images should use that service page's Yoast focus keyphrase more directly.
- Alt text describes the visible image first, then uses the service/location phrase naturally.
- Home Service Areas images should show the local place rather than the service work, while still using natural `{service + location}` filename and alt text targeting.
- Services hub images reuse Home Page service images for matching primary services and generate new visuals only for additional services.
