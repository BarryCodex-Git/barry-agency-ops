# Prompt: New Client Homepage Build

Use this prompt when starting a new client homepage build.

```text
Barry, let's take on a new client.

Use [website/development domain].

Build the Home Page first.

Follow the New Client Homepage Builder workflow.

For the full new-client setup, build:
- Home Page first
- Services Hub Page next
- Service Areas Hub Page next
- Every primary and additional Service Page from intake
- Blog infrastructure and three real starter posts

Use the five primary services on the Home Page.
Use the five primary services plus all additional services on the Services Hub Page.
Use the primary service area regions from intake on the Service Areas Hub Page.
Barry must research 8-12 high-value sub-locations/suburbs per primary service area unless exact suburbs are supplied.

If any client intake information is missing, ask me for it before writing or applying final content.

Use Elementor MCP where possible.

Use Yoast SEO.

This is an Elementor master-template conversion. Do not build WordPress block editor pages, custom HTML pages, or a standalone replacement site.

Use client images first. If no suitable client images exist, automatically use relevant free/Creative Commons stock images, resize them to fit the existing containers, and apply SEO filenames and alt text.

Before generating AI images, inspect the client folder, `assets/AI Images/`, `assets/AI Images/brand guide/`, approved generated images, `image-plan.md`, and `brand-image-rules.md` if present. Use those examples as the image style, branding, local setting, vehicle, uniform and equipment reference.

Before generating or selecting multiple AI images, create a quick image variety plan. Avoid repeating the same person, pose, stance, facial expression, equipment angle or composition with only the background changed. Vary scenarios, team members, expressions, service examples, camera framing, tools, vehicles, local settings and job actions.

Preserve the approved master section order, containers, widgets and image-slot dimensions on every template page unless I specifically ask for a restructure. This is a content, branding and SEO conversion, not a redesign.

Before applying content, confirm that the imported Elementor Home, Services, Service Areas, Blog and Service Page Template records exist. If a needed page is missing, duplicate the approved Elementor template source instead of creating a blank/block-editor page.

Do not change the approved Global Contact CTA button text. Update only the client contact links and data required by the global buttons.

Write in a relevant, local, authentic, human tone. Do not make it sound like a sales pitch.

Apply Barry's Elementor labelling standard to all new or modified sections and fields.

Open the published Home page in Chrome after changes so I can review it.
```

## Expected Barry Flow

1. Resolve website/domain.
2. Confirm access and MCP readiness.
3. Confirm the target pages/templates are Elementor records from the approved master.
4. Ask for missing client intake data.
5. Draft homepage content.
6. Prepare SEO fields.
7. Prepare image plan, including visual variety and duplicate-image checks.
8. Apply Home Page content through Elementor MCP.
9. Build Services Hub Page if full setup is requested.
10. Build Service Areas Hub Page if full setup is requested.
11. Duplicate the approved Elementor service template for every primary and additional service, write unique service-specific content, apply Yoast data, nest each page under Services, and connect menus and internal links.
12. Build the Blog infrastructure and three real starter posts.
13. Apply labels/classes.
14. Open published pages for review.
15. Report status and approval items.
